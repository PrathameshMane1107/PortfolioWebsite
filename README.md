Responsive Multi-Page Portfolio Website

Project Overview:-
This project is a responsive multi-page portfolio website built using HTML, CSS, JavaScript, and Bootstrap. It showcases a fictional creative professional’s work with interactive features and a modern design, ensuring a smooth user experience across devices.

Features-
✅ Fully responsive layout (Mobile, Tablet, Desktop)
✅ Home Page: Hero section, services, testimonials, blog preview, and contact form
✅ Portfolio Page: Filterable gallery with lightbox effect
✅ Blog Section: Paginated blog posts with "Read More" functionality and dark mode toggle
✅ Contact Page: Bootstrap contact form with JavaScript validation and embedded Google Maps
✅ Interactive Navbar, Smooth Scrolling, and Back-to-Top Button
✅ Live Chat Widget Simulation

Technologies Used-
HTML5 – For structuring the website
CSS3 – For styling and animations
Bootstrap 5 – For responsive design and UI components
JavaScript (ES6) – For interactive features
Google Maps API – For location embedding

How to Use-
1. From Homepage you can know basic info
2. Click on Portfolio Page to view filtered projects.
3. Use the Blog Section to read posts, toggle dark mode, and navigate through pagination.
4. Fill out the Contact Form (JavaScript validation included).
5. Use the Live Chat Widget for simulated interaction.

Customization(If You Want)-
1. Modify images and text inside the index.html, portfolio.html, and blog.html files.
2. Update styles in styles.css for color changes.
3. Enhance JavaScript interactions inside script.js.
